# Musician Biography Website

A simple website made to introduce a musician and share their story, music, and photos in one place. The project was built as a front-end web page with a few different sections so visitors can move around the site and learn more about the artist.

## Overview

This website includes a homepage, information about the musician, a gallery, a music section, and a contact page. The goal was to make the site feel clean and easy to use while still giving the musician a strong online presence.

## Included Pages

- Home page
- About page
- Gallery page
- Music page
- Contact page

## Main Features

- Biography and artist information
- Gallery for images and media
- Music-related content and presentation
- Contact section for inquiries
- Can be used on both the computer and mobile devices

## Project Notes

The site was built using HTML, CSS, and JavaScript, with a simple structure that keeps the content easy to edit and update. The design focuses on readability, visual balance, and making the musician's work the main focus.
